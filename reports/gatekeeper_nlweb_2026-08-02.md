# AIの聞き方を NLWeb に合わせた — 2026-08-02

## 何が問題だったか

監査（[gatekeeper_audit_2026-08-02.md](gatekeeper_audit_2026-08-02.md)）で残した最後の1件。

門番は「AIが何を探しに来たか」を `?q=` という**自分ルール**で受け取っていた。
**実際のAIエージェントは、各サイト独自のクエリなんて付けてこない。**
すると項目が特定できず、`isAnswered` は「1つでも答えがあれば取れた扱い」に倒れる。

> 本物のAIが来ると、ほぼ全件 `answered=true` になり、
> **主役の「取れずに帰った」が1件も残らない。**

作品の芯（「AIが来て、答えを見つけられずに帰った」を記録する）が実運用で空回りする、
という構造的な問題だった。

## 探した（作る前に）

**「エージェント同士の会話の事例も増えている。参考にしていい」**（本人・2026-08-02）を受けて、
自分で受け取り方を発明する前に世の中を見た。

| 見つけたもの | 何が書いてあったか |
|---|---|
| **NLWeb**（Microsoft・2025 Build発表、R.V. Guha 主導） | サイトを自然言語で聞ける窓口にする公開プロトコル。**`POST /ask` の `query.text` に質問がそのまま入る**。返答の型に **`answer` / `elicitation` / `promise` / `failure`**。どのインスタンスも同時にMCPサーバー。採用: Shopify / Snowflake / O'Reilly / Tripadvisor / Eventbrite / Hearst |
| **Cloudflare のNLWeb記事** | Workers 上に `/ask` と `/mcp` を持つWorkerとして載せる手順。**門番と同じ場所** |
| **Web Bot Auth architecture draft-05**（2026-03-02） | §4.2.3「エージェントは署名にヘッダを追加してよい。例: **意図を表すHTTPヘッダを署名する**」。ただし**ヘッダ名は標準化されていない**（`purpose` は draft 04 で削除済み） |

**結論: 受け取り方を発明する必要はなかった。**

そして決定的だったのが、**「答えが出せなかった」が NLWeb の `failure` として規格に既にある**こと。
我々が数えたい「取れずに帰った」は自作の概念ではなく、**この規格の型そのもの**だった。

さらに **`elicitation`（聞き返し）** が、曖昧な問いへの規格側の正解だった。
黙って「取れた」に倒すのではなく、聞き返す。これがそのまま①の直し方になった。

Web Bot Auth の「意図ヘッダ」は名前が決まっていないので、それ単独では成り立たない。
NLWeb で受け取り、必要なら署名対象に含める、という順序が素直。

## やったこと

`POST /ask` を1本足した（`gatekeeper/nlweb.mjs`）。仕様どおりに3つの型を返す。

| 聞かれたもの | 返す型 | 記録 |
|---|---|---|
| 書いてある項目 | `answer`（schema.org `GovernmentService` ＋ 実測値） | `answered: true` |
| **書かれていない項目** | **`failure` / `NO_RESULTS`** | **`answered: false`** ←主役 |
| どの項目か分からない | `elicitation`（選択肢つきで聞き返す） | `answered: null` |

決めたこと:

- **曖昧な問いを「取れた」に倒さない。** 聞き返した分は `totals.undetermined` として別に数える。
  推測で数えれば「取れた」が増えて見栄えは良くなるが、それは嘘になる
- **聞き返しの選択肢は、実測で値がある項目だけ**（空の項目を勧めない）
- `results` の `fields` は **schema.org の語彙ではなく AI読の実測値そのもの**。
  盛らない・作らない。`note`（行政の公式発表ではない旨）も必ず付いていく
- 署名なし（＝人間）にも答えは返すが、**記録はしない**（既存の原則どおり）
- `?q=` の口はそのまま残した（既存の23本のテストが通る）

answer / failure / elicitation が規格どおり返る**ことを確認済み。

## まだやっていないこと

- **`/mcp`**（NLWeb は各インスタンスがMCPサーバーにもなる）。今回は `/ask` 1本に絞った
- **`site` を省略されたときの既定ページ**。いまは host をキーに引くだけ
- Web Bot Auth の「意図ヘッダを署名対象に含める」。ヘッダ名が標準化されてから
- **本物のAIエージェントからの実リクエスト**。相手が来てくれないと確かめられない
