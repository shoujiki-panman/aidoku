# 公開データについて

AI読（アイドク）が測った結果です。**使うのに許可は要りません。**
ただし、混ざっているものが2種類あるので、そこだけ先に書きます。

| | |

| クレジット表記 | `正直パンマン「AI読（アイドク）」 https://github.com/shoujiki-panman/aidoku` |

「こちらが作った部分」＝ **点数・集計・改善案・到達クリック数・観察記録**。

### CC BY 4.0 に**含まれない**もの

**`fields[].agent_value`（自治体サイトから抜き出した実際の文）。**

これは各自治体の公式サイトに書かれている文そのもので、**著作権は各自治体にあります。**
判定の根拠を示すために引用しています。出典は各レコードの `page_url`。

再利用したい場合は、**各自治体の利用規約を確認してください。**
こちらのライセンスで再配布を許可することはできません。

> 画面には、自治体サイトから抜き出した文を **124か所・計約10,700文字**出しています
> （1件あたり最大200文字）。2026-08-15 時点。

## 列の意味

### ファイルの先頭

| キー | 意味 |
|---|---|
| `generated_at` | このファイルを書き出した時刻（UTC・ISO 8601）。**測った日ではない** |
| `procedure` / `procedure_id` | 手続きの名前とID |
| `question` | 住民がAIにする想定の質問。`{muni}` が自治体名に置き換わる |
| `phase` | 対象の範囲（`23区`） |
| `n_municipalities` | 件数 |
| `summary` | 全体の集計（下記） |
| `municipalities` | 自治体ごとの結果（下記） |
| `disclaimer` / `license` / `sources` | 但し書き・ライセンス・出典 |

### `summary`

| キー | 意味 |
|---|---|
| `average` | 合計点の平均（0〜100） |
| `max` / `min` | 最高点・最低点 |
| `full_marks` | **4項目すべて**が読めた自治体の数（オンライン明示は数に入れない） |
| `zero` | 合計0点の自治体の数 |
| `fee_missing` | 手数料が読めなかった自治体の数 |

### `municipalities[]`

| キー | 意味 | 取りうる値 |
|---|---|---|
| `id` | 自治体ID | `setagaya` など |
| `name` | 自治体名 | `世田谷区` など |
| `total` | 合計点 | 0〜100 |
| `breakdown` | 項目ごとの点 | 下記 |
| `hops` | トップページから何クリックで着いたか | 1〜3、`null`（不明） |
| `page_url` | 採点したページ | URL |
| `followed` | 追加で読んだリンク先 | 0〜2件の配列。**空配列は「追わなかった」** |
| `fields` | 項目ごとの詳細 | 下記 |
| `improvements` | 改善案 | 下記 |
| `notes` | なぜ読めないかの観察記録 | 文字列。**空文字のことがある** |

### `breakdown`

キーは5つ。**`必要書類` `窓口/オンライン可否` `期限` `手数料` は 0 か 20 の2値です。**
中間の値は出ません。だから**判定が1つ変わると20点動きます。**

`オンライン明示` だけ 3値 — `20`（明記）/ `10`（曖昧）/ `0`（記載なし）。

### `fields[]`

| キー | 意味 | 取りうる値 |
|---|---|---|
| `field` | 項目名 | 上記4つ |
| `verdict` | 判定 | `読めた` / `読めない` |
| `points` | 点 | `20` / `0` |
| `agent_value` | **AIが実際に読み取った文**（自治体サイトの文） | 最大200文字。読めなかったときは空文字 |

**`agent_value` は200文字で切ってあります。**元の文の続きは `page_url` を見てください。

### `improvements[]`

読めなかった項目にだけ出ます。全部読めた自治体では**空配列**。

| キー | 意味 |
|---|---|
| `field` | 直す項目 |
| `gain` | 直すと増える点（20、オンライン明示は 10 か 20） |
| `reason` | 何をどう書けばよいか |

---

## 欠損の扱い

- **`hops` が `null`** → 到達の記録が取れなかった。**0クリックではない**
- **`agent_value` が空文字** → そのページから読み取れなかった。**「無料」等の値が空という意味ではない**
- **`followed` が空配列** → 追加のリンクを読まなかった。**リンクが無かったとは限らない**
- **`notes` が空文字** → 観察記録が無い。読める場合はたいてい空

## 測り方と、揃っていないところ

**測り方は [`../../METHOD.md`](../../METHOD.md) に1枚でまとめてあります。**
条件が揃っていない箇所も**そこに全部書いてあります。**使う前に読んでください。

特に:

- **転入届だけ、23区を同じ日に測っていません**（2026-07-21 に3件・07-22 に20件・08-05 に1件）
- **点数のぶれ幅は測っていません。**各1回の判定です
- 各項目は2値なので、**判定が1つ変われば20点動きます**
