# 公開データについて

AI読（アイドク）が測った結果です。**使うのに許可は要りません。**
ただし、混ざっているものが2種類あるので、そこだけ先に書きます。

## ライセンス

| | |
|---|---|
| **こちらが作った部分** | **CC BY 4.0** |
| クレジット表記 | `正直パンマン「AI読（アイドク）」 https://github.com/shoujiki-panman/aidoku` |

「こちらが作った部分」＝ **点数・集計・改善案・到達クリック数・観察記録**。

### CC BY 4.0 に**含まれない**もの

**`fields[].agent_value`（自治体サイトから抜き出した実際の文）。**

これは各自治体の公式サイトに書かれている文そのもので、**著作権は各自治体にあります。**
判定の根拠を示すために引用しています。出典は各レコードの `page_url`。

再利用したい場合は、**各自治体の利用規約を確認してください。**
こちらのライセンスで再配布を許可することはできません。

> 画面には、自治体サイトから抜き出した文を **124か所・計約10,700文字**出しています
> （1件あたり最大200文字）。2026-08-15 時点。

## 列の意味

### ファイルの先頭

| キー | 意味 |
|---|---|
| `generated_at` | このファイルを書き出した時刻（UTC・ISO 8601）。**測った日ではない** |
| `procedure` / `procedure_id` | 手続きの名前とID |
| `question` | 画面表示用の会話文。測定用の質問はextract JSONの`test_cases[]`にfact_type単位で残る |
| `phase` | 対象の範囲（`23区`） |
| `n_municipalities` | 件数 |
| `measurement` | 測定条件・互換性・自治体ごとの実行時刻（下記） |
| `summary` | 全体の集計（下記） |
| `municipalities` | 自治体ごとの結果（下記） |
| `disclaimer` / `license` / `sources` | 但し書き・ライセンス・出典 |

### `measurement`

| キー | 意味 |
|---|---|
| `recording_status` | `recorded`（条件記録あり）/ `legacy_unknown`（記録開始前） |
| `comparison_status` | `compatible`（条件一致）/ `legacy_unknown`（比較できない） |
| `measurement_version` / `prompt_version` | 測定方法とプロンプト本文の版 |
| `follow` / `max_follow` | リンク追従を有効にしたか、その上限 |
| `max_depth` / `beam` / `max_fetches` | 探索条件 |
| `max_text_chars` / `max_links` | AIへ渡す本文・リンクの上限 |
| `model` / `model_version` | 実行手段と指定モデル |
| `run_at` / `discovery_run_at` | 含まれる抽出・探索実行時刻の一覧 |
| `runs` | 自治体ID・モデル・実行時刻の対応表 |

`run_at` だけが違う結果は同じ条件として集計できる。その他の条件が1つでも違う場合、
`export_dashboard.py` は公開JSONを書かずに停止する。新しい記録と `legacy_unknown` も混ぜない。

現在の公開23区データは記録開始前に測ったため `legacy_unknown`。現在のコード値を
過去の実測値として後付けしていない。

### `summary`

| キー | 意味 |
|---|---|
| `average` | 4判定まで完了した自治体だけの合計点平均。0件なら `null` |
| `max` / `min` | 検証済みの最高点・最低点。0件なら `null` |
| `full_marks` | 4項目すべてがEvaluatorを通った自治体の数 |
| `zero` | 検証済み合計が0点の自治体の数。未検証は含めない |
| `answered_all_four` / `answered_zero` | AI回答が4項目すべて返った／1つも返らなかった自治体数。正解数ではない |
| `evaluated` / `not_evaluated` | 4判定まで完了した／未完了の自治体数 |
| `fee_missing` | 手数料についてAI回答が無かった自治体の数 |

### `municipalities[]`

| キー | 意味 | 取りうる値 |
|---|---|---|
| `id` | 自治体ID（このプロジェクト内でだけ通じる） | `setagaya` など |
| `lg_code` | **全国地方公共団体コード（6桁）** | `131121` など。**他のデータと繋ぐならこれを使う** |
| `name` | 自治体名 | `世田谷区` など |
| `total` | 4判定を通った合計点 | 0〜100、必要な判定が未実施なら `null` |
| `breakdown` | 項目ごとの検証済み点 | 下記 |
| `answered_count` | AI回答が返った項目数。正解数ではない | 0〜4 |
| `evaluation_status` | 自治体4項目の評価状態 | `evaluated` / `not_checked` |
| `hops` | トップページから何クリックで着いたか | 1〜3、`null`（不明） |
| `page_url` | 採点したページ | URL |
| `followed` | 追加で読んだリンク先 | 0〜2件の配列。**空配列は「追わなかった」** |
| `fields` | 項目ごとの詳細 | 下記 |
| `improvements` | 改善案 | 下記 |
| `notes` | なぜ読めないかの観察記録 | 文字列。**空文字のことがある** |

### `breakdown`

キーは5つ。`必要書類` `窓口/オンライン可否` `期限` `手数料` は、
4判定をすべて通れば `20`、1つでも失敗すれば `0`、必要な判定が未実施なら
`null` です。`found=true`だけでは20点になりません。

`オンライン明示` だけ 3値 — `20`（明記）/ `10`（曖昧）/ `0`（記載なし）。

### `fields[]`

| キー | 意味 | 取りうる値 |
|---|---|---|
| `field` | 項目名 | 上記4つ |
| `verdict` | 旧画面との互換用の回答観測 | `読めた` / `読めない`。正解判定ではない |
| `answered` | AI回答が返ったか。正解かどうかではない | `true` / `false` |
| `points` | 4判定を通った点 | `20` / `0` / `null` |
| `evaluation_status` | 4判定の全体状態 | `pass` / `fail` / `not_checked` |
| `evaluation` | Evaluatorの版、4判定の状態、全体状態。詳しい理由はscorer出力に残す | object |
| `agent_value` | **AIが実際に読み取った文**（自治体サイトの文） | 最大200文字。読めなかったときは空文字 |

**`agent_value` は200文字で切ってあります。**元の文の続きは `page_url` を見てください。

### `improvements[]`

読めなかった項目にだけ出ます。全部読めた自治体では**空配列**。

| キー | 意味 |
|---|---|
| `field` | 直す項目 |
| `gain` | 検証済みなら直すと増える点。未検証なら `null` |
| `reason` | 何をどう書けばよいか |

## 欠損の扱い

- **`lg_code` が `null`** → コードを付けられなかった自治体。**行を落とさず残してある**
- **`hops` が `null`** → 到達の記録が取れなかった。**0クリックではない**
- **`agent_value` が空文字** → そのページから読み取れなかった。**「無料」等の値が空という意味ではない**
- **`points` / `total` が `null`** → 必要な4判定が終わっていない。0点ではない
- **`answered=true`** → AI回答が返った。正解確認済みという意味ではない
- **`followed` が空配列** → 追加のリンクを読まなかった。**リンクが無かったとは限らない**
- **`notes` が空文字** → 観察記録が無い。読める場合はたいてい空
- **`measurement.recording_status` が `legacy_unknown`** → 条件が同じという意味ではない。
  比較に必要な記録が残っていない

## 測り方と、揃っていないところ

**測り方は [`../../METHOD.md`](../../METHOD.md) に1枚でまとめてあります。**
条件が揃っていない箇所も**そこに全部書いてあります。**使う前に読んでください。

特に:

- **転入届だけ、23区を同じ日に測っていません**（2026-07-21 に3件・07-22 に20件・08-05 に1件）
- **既存23区データのGround Truthは揃っていません。**回答の観測値は残し、正解点は未検証です
- 4判定のうち1つでも未実施なら、点数を後付けで推測しません
