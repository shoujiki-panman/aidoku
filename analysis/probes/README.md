# 一度きりの調べもの（probes）— 何を聞いて、何が分かったか

**ここは本流ではありません。** 公開データを作る道具は `analysis/` 直下にあります。
ここにあるのは**問いに1回答えて、役目を終えたスクリプト**です。

## なぜ分けたか

`analysis/` に37本が並び、そのうち16本（43%）が一度きりのものでした。
本流と混ざっているせいで、**どれが毎回走るものか、どれが答えの出た調べものか**が
見分けられませんでした。

そして本当の害はそこではありません。**同じ問いを二度調べたことです。**
この索引は、**聞く前に「もう答えが出ていないか」を見る場所**です。

> 新しく調べたくなったら、まずこの表を見る。
> 答えが出ている問いを、もう一度 LLM を回して調べ直さない。

## 出た答え

| 問い | 答え | 道具 |
|---|---|---|
| 見出し（達成基準 2.4.6）が、AI読の見ている問題の主因か | **主因ではなかった** | `check_headings.py` |
| リンク題（2.4.4）が主因か | **主因ではなかった**（4.2% / 2.7%） | `check_link_text.py` |
| サイト内検索を使えば読めるようになるか | **ならない。**区自身のURLで叩ける検索は24自治体中**0** | `check_search.py` |
| 起点ページの選び方が本文量と食い違っているか | **「長い＝正しい」は成り立たない。**最初27組と数えたのは誤りで、確実に言えるのは4組（下限） | `check_pick.py` |
| 区の外のホストが混ざっていないか | **混ざっていた。**候補2,102本中154本・31組。同一ホスト判定が部分一致で壊れていた | `check_host.py` |
| 表の中にしかない項目はどれだけあるか | 4セル・6項目（見積もりの5セルではなかった） | `check_tables.py` |
| 「記載なし」のうち、見に行っていないものは | 切り分けた。虱潰しの土台になった | `never_looked.py` |
| プロンプトを変えればリンクを開くようになるか | A/Bで確認済み | `try_follow_prompt.py` |
| 読ませなかった候補に答えがあったか | 調べた（LLMを1回も呼ばない） | `check_unread.py` |
| 4項目とも読めなかった組で、採点しなかった候補に答えがあるか | 調べた | `scan_unpicked_candidates.py` |
| 外部の変換器（anydoc）の方がよく読めるか | 突き合わせ済み → `plans/decisions/external-reader.md` | `compare_readers.py` |
| 読めない画像PDFはOCRで読めるか | 読めた。**その後 OCR は測定本体に入れた**（`plans/decisions/ocr-in-measurement.md`）ので、この道具は役目を終えている | `ocr_unreadable.py` |
| リンクの並べ替えで渡せるリンクは増えるか | 増えた → `plans/decisions/link-order.md` | `check_link_order.py` |
| 対外文に書いた数字は、いまの実測と合っているか | 突き合わせる道具。**数字を対外に出す前に走らせる** | `check_claims.py` |

## 置き場の決まり

- **調べもの本体**はここ（`analysis/probes/`）
- **テストは根**（`test_<名前>.py`）。他の調べもののテストと揃える
- **結論は `METHOD.md` か `plans/decisions/` に書く。** ここのコードが消えても
  結論が残るように。コードは結論の裏付けであって、結論の置き場ではない
