## なぜ要るか

見張り（`check-pages`、毎朝 08:00 JST）は動いている。だが**その先で止まっている。**

- 2026-09-22 の見張り: 68ページ中 **45ページが「変わった」**（`web/data/site-status.json`）
- 見張りは測り直さない（`_about` にそう書いてある）。測り直しは手動で、誰も回していない
- `NOW.md` は 2026-09-10 から再生成されていない。公開データは 9.9日前のまま

**AI読を毎日使う人がいない。** 作った本人も含めて。
区の担当者向けの画面を作る前に、まず本人が毎朝使う形にする。

## 何が届くか

毎朝1通。**前回から変わったものだけ。**

```
AI読 2026-09-24（測り直し 6ページ / 残り 39）

上がった
  墨田区 児童手当 40→60  手数料の記載が読めるようになった
下がった
  新宿区 転入届 80→60  窓口の欄が読めなくなった
点は同じ（ページだけ変わった）
  港区 粗大ごみ ほか3件
読めなかった
  足立区 転入届  404
```

変化が無い日も「変化なし」の1行を出す（届かないのか、変化が無いのかを区別するため）。

## 合格ライン（全部通ったら完成）

1. 見張りの翌朝、その日の1通が `outputs/daily/YYYY-MM-DD.md` にある
2. 各行に **区・手続き・前→今の点・変わった項目**がある。ページURLは本文に
3. **条件（`CONDITION_KEYS`）が違う記録どうしは比べない。** 比べられない行は「条件が違うため比較せず」と出す
4. 1日に測り直すのは**上限 N ページ**まで。途中で落ちても、翌日は残りから続ける
5. **公開データ（`web/data`）は書き換えない。** 公開は本人が1通を見て決める（`remeasure.md` と同じ方針）
6. 測り直したページは、翌日の「変わった」に二度と出ない（基準が更新される）
7. 測定に使う `claude -p` は**ツールを全部塞いだ状態**で呼ばれている（下の「先にやること」）

## 先にやること — 測定の穴を塞ぐ

2026-09-23 に確かめた。`claude -p` を呼ぶ3か所とも、ツールが開いている。

| 場所 | 今の状態 | 困ること |
|---|---|---|
| `extractor/fact_extract.py:128` | 何も塞いでいない。cwd はリポジトリ | 渡したページ以外を取りに行ける。**リポジトリの golden も読める** |
| `scorer/score.py:143` | 何も塞いでいない | 採点器が外を見て判定できる |
| `experiment/cold_ask.py:92` | WebSearch と WebFetch だけ | 「検索なし」のはずが、Bash（curl）や MCP で取りに行ける |

直し方は同じ: `--tools ""` と `--strict-mcp-config`、cwd を中立なディレクトリにする。
**これを直すまで毎日の測り直しは回さない。** 毎日まちがった数字が届くことになるため。

直したら `measurement_signature` に塞いだことを記録する（条件が変わるので、旧データとは自動で別物になる）。

## どこで動かすか

- **手元の Mac で動かす。** `claude -p` はログインが要るので、GitHub Actions では動かせない
- 見張り（Actions）→ `git pull` → 変わったページだけ**その場で取得して**測り直す → 1通を書く
- `remeasure.md` の測り直しはキャッシュの再生（ページを固定してモデルを比べる）。
  **こちらは逆で、ページの変化を見る**ので、キャッシュを使わず取りに行く。
  取得の作法（robots.txt・3秒間隔）は `crawler/` のものをそのまま使う

## 順番

1. 測定の穴を塞ぐ（上の表の3か所）。テストで `--tools ""` が付いていることを固定する
2. 1ページだけ手で通す: 変わったページ1つを取り直し → 抽出 → 採点 → 前回と比べる
3. 1通を書く部分（差分 → Markdown）。LLM を呼ばない。テストあり
4. 上限 N ページで回し、残りを翌日へ持ち越す
5. 毎朝の自動起動（launchd）
6. 1週間使ってみて、届け先（ファイルのままか、通知か）を決める

## やらないこと

- **公開データを自動で書き換えない**
- **区の担当者向けの画面は作らない。** それは `spec-fix-app.md`
- **対象を広げない。** 24自治体 × 3手続きのまま
- 1日の上限を超えて一気に片付けない（利用上限で落ちた実績がある。`remeasure.md` の 08-28）

## 決まっていないこと（本人に聞く）

- 1日の上限 N（初回は 45ページの積み残しがある。6ページ/日なら 8日で片付く）
- 届け先: ファイルだけ／macOS の通知／スマホ
- 起動時刻（見張りは 08:00 JST。その後ならいつでもよい）
