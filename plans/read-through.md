## 問題

AI読は「23区中22区が転入届の手数料を書いていない」と言ってきた。
だがそれは **うちの読み取り器が「記載なし」と言った** だけである。

2026-08-25 に実データを数えたら、こうだった（転入届・24自治体）:

| | 本数 |
|---|---|
| 探索が見つけた候補URL | **592** |
| うち取得済み（本文200字超） | 558 |
| **読み取り器に渡したページ** | **41**（7%） |
| **渡さなかったうち、リンク題に「転入」等が入る本命ページ** | **305** |

ほぼ全区で **1本しか開いていない**。同じ区に、題に「転入届」と書いてあるページが
平均13本あって、そこには行っていない。実物:

- 目黒区「転入届：本人または新しく同じ世帯になるかたが手続きをするとき」（点39）**未読**
- 練馬区「転入届（国外から練馬区に引越したとき）」（点42）**未読**
- 江東区「国外への転出届・国外からの転入届」（点36）**未読**
- 葛飾区「転入届」（点24）**未読**

**だから「書いていない」は、いま言えない。**
書いていないのか、305本の方に書いてあったのかが分かれていない。

さらに悪いことに、**「なぜ開かなかったか」はどこにも記録がない。**
`crawler/out/discovery_*.json` は候補を点数つきで残しているが、
抽出側が何を選び、何を捨て、なぜ捨てたかは残らない。
記録が無いので、**読み切ったと主張することが原理的にできない。**

### 影響範囲（この計画が正しければ、下は全部やり直し）

- `web/data/scores-*.json` の「読めた／読めない」判定
- `experiment/out/fee-ask_search.json` の「22区が書いていない」（2026-08-25）
- デッキ・台本の「手数料は22区で見つかりません」

## 読むべきは305本ではなく90本

キャッシュ済み297本（773,119字）を機械的に見た内訳:

| | 本数 |
|---|---|
| 本命の未読ページ | 305 |
| うち PDF / Word / Excel（読む道具が無い） | **5** |
| うち本文が手元に無い（要取得） | 3 |
| うち本文がキャッシュ済み | 297（773,119字） |
| **うち手数料の語（手数料/費用/無料/かかりません）を含む** | **90** |

**手数料1項目なら、読ませるのは90本で足りる。** 平均3.75本/自治体。

品川区・豊島区は **0本**。この2区は「書いていない」が先に確定に近づく。
港区は11本（唯一「読めた」区。上がりようはないが、根拠が増えるかの検算に使える）。

### 全部読ませてはいけない（実測で確認済み）

語だけで絞ると **24/24自治体が当たった**。中身を読むと外れだった:

- 荒川区「住民票の写し 1通につき300円」← **住民票の手数料**
- 中央区「戸籍謄本 1通：450円」← **戸籍の手数料**
- 板橋区「Adobe Reader をダウンロード（無料）」
- 足立区「プラネタリウム 入場無料」

**転入届の手数料ではない。** 表読みのときと同じ失敗（見積もり12セル→実際4セル、
`plans/decisions/table-reading.md`）。**手続きで絞ってから読む。**

| # | やること | 受け入れ条件 |

| ① | **探索台帳** — 候補1本ごとに「渡した／渡さなかった・理由・点数」を残す | 転入届24自治体の候補**592本すべてに理由がつく**。理由が空欄のものが**0件** |
| ② | **読み切る** — 本命かつ手数料語を含む90本を読解に渡す | 「22区が書いていない」が**何区に変わるか**が出る。変わった区は**URL＋原文の引用位置つき** |
| ③ | **非HTMLを読む** — PDF / Word / Excel 5本 | 5本すべてに「読めた／読めない（なぜ）」がつく。**読めないものも記録する** |

**①が先。** ②③で点が動いても、台帳が無ければ「読み切った上で無い」と言えない。

## 測定条件に署名する（MUST）

`measurement.py` の `CONDITION_KEYS` に足す:

| キー | 値の例 | なぜ要る |
|---|---|---|
| `read_breadth` | `"agent_pick_2"` → `"strong_all"` | 読ませる範囲。**ここが変わると点が動く** |
| `non_html_reading` | `null` → `"pdf_text"` | ③の有無 |

**足さないと、道具を良くして上がった点が「サイトが直った」に見える。**
`link_order` / `table_reading` で2回やったのと同じ扱いにする。
公開済み `scores-*.json` には旧条件として `null` を追記する
（追記しないと `measurement_signature()` が KeyError で落ちる）。

条件が違う記録どうしは、これまでどおり **比較を拒否する**（`attribution()` が unknown を返す）。

## やらないこと（と理由）

- **592本ぜんぶ読ませない。** 手続きで絞らないと他手続きの手数料を拾う（上の実測）。
  範囲を広げるのは、90本の結果を見てから
- **判定基準を変えない。** 4項目の必須要素は人が決めたまま。
  この計画は **渡す範囲**だけを変える。基準を一緒に動かすと、何が効いたか分からなくなる
- **再クロールしない。** 297本は既に手元にある（`crawler/cache` 270MB）。
  区のサーバーに同じものを取りに行かない
- **本文を再配布しない。** `quote_withheld` を維持。読み取って判定するだけで、原文は持たない
- **他の手続き（児童手当・粗大ごみ）は後。** まず転入届・手数料1項目で通し方を確定する
- **公開サイトはまだ触らない。** 数字が動くと分かってから直す。中途半端に混ぜない
