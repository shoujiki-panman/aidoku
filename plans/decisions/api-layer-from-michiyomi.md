# 配信層の形を「みちよみ」に合わせる

Status: 参考として採用（2026-08-22）。**実装は通過後**
関連: [`plans/measurement-harness.md`](../measurement-harness.md)、`gatekeeper/`

## 何を見たか

**みちよみ**（https://michiyomi.dev/）— Mapillary の街路画像を機械可読な都市環境データとして
配信するAPI。**2026-08-22 に本人が原文を開いて確認した事実**:

- 588,220件の言語化済み街路シーン、2,522件の裁定済み経年変化
- 「REST + MCP」を**同じデータ契約**で提供
- **認証不要の read-only API**
- 出典 Mapillary / ライセンス **CC BY-SA 4.0**
- 全件に**世代（どのモデルで言語化したか）と来歴**を添える
- **coverage エンドポイント**があり、「データが無い場所は正直に0件と返す」
- **APIの自己記述JSONが `/v1`** にある

**運営主体はサイトに記載がありません。** 「個人開発」と断定はできません。
確実に言えるのは**国交省など公的機関の事業だと名乗ってはいない**ことだけなので、
資料で引くときは「Mapillary（CC BY-SA 4.0）を出典とする第三者API」と書きます。
出典を国の事業と混同しない。

立場はAI読と逆です。**みちよみ＝AIが読める形を作る供給側、AI読＝既存サイトが
AIから読めるかを測る評価側**。競合ではなく補完で、対比材料として使えます。

## AI読はどこまで来ているか（点検した結果）

| みちよみの設計点 | AI読の現状 |
|---|---|
| ① REST と MCP を同一契約で | **ほぼ出来ている。** `gatekeeper/mcp.mjs` は NLWeb 仕様 Appendix C.1 に従い、MCP `ask` が HTTP `/ask` と**同じレスポンス本体**を返す。独自ツールを生やしていない |
| ② 認証不要の read-only | **出来ている。** `web/data/*.json` は GitHub Pages が誰にでも配る。CC BY 4.0 |
| ③ 事実／決定論的計算／モデル解釈を分ける | **半分。** `fields[].verdict`（yes/no）→ `points` は `scorer/score.py` が**機械的に**出し、LLMに「正解/部分正解」を選ばせない。一方 `notes` はLLMの散文で、同じJSONに同居している。名前空間は分かれていない |
| ④ 世代と来歴を全件に | **出来ている。** `measurement.py` が model / model_version / prompt_version など12条件をハッシュ化し、`generated_at` と共に返す |
| ⑤ 無い場所は正直に0件 | **出来ている。** 「測っていない」と「測って0点」を色で分け、`wardmap.js` は未測定を `tone:'unknown'` / `got:null` にする（0にしない） |
| ⑥ 推定値であることの明示 | **出来ている。** 各ページの `.dads-notification-banner` に「行政機関の公式発表ではありません」 |
| ⑦ 自己記述JSONを `/v1` に | **無い。** `web/data/README.md` は人間向けの散文で、機械可読な目次が無い |

## 決めたこと

### 採る: ③の分離、⑦の自己記述JSON

**⑦が一番刺さります。** 「AIから叩ける形であるべきだ」と測って回っている当人が、
自分のデータには機械可読な目次を持っていない。`web/data/index.json`
（各ファイルの意味・列の定義・生成日時・ライセンス・被覆状況）を置けば、
主張と実装が一致します。**30分ほどの作業**で、提出前にも入れられます。

③は `notes`（LLMの散文）を別名前空間に移す話で、既存の消費者を壊すので**通過後**。

### 採らない（そのままでは）: ①の `/v1/score` 公開

**判定は `claude -p` です。誰でも叩ける `/v1/score` は、他人が
こちらのアカウントでLLMを走らせられる口になります。** 費用も、相手サーバーへの
クロールも、こちらが負う。サイト内チャットボットを入れないと決めたのと同じ理由です
（[`measure-to-tool.md`](measure-to-tool.md)）。

出すなら**測定済みの結果を返す read-only の `/v1/score`** で、
新規測定は受け付けない。新しい自治体の測定要求は、キューに積んで
ハーネス（[`measurement-harness.md`](../measurement-harness.md)）が回す形にする。
みちよみも配信しているのは**測り終えたデータ**であって、その場で走る推論ではありません。

## 資料での引き方（First Stage）

> 個人・小規模の第三者APIが、REST と MCP を同じ契約で、来歴つき・認証不要で
> 既にAIに街を開いている（みちよみ / 出典 Mapillary・CC BY-SA 4.0）。
> 一方、東京23区の行政手続きページは **HTMLの可読性の段階で詰まっている**。

**「国交省の事業」とは書かない。** 運営主体はサイトに記載がない。
