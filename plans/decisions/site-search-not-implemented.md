# サイト内検索は使わない（作る前に測って、作らないと決めた）

Status: 決定（2026-09-02）
Tracks: `analysis/probes/check_search.py` / `analysis/out/search_forms.json`

## 問題

住民のAIが最初にやることの一つが「サイト内検索に語を入れる」。
だが AI読は**リンクしか辿っていない**。検索窓を一度も使っていない。

「検索窓を使えば読めるのに、使っていないから読めないと言っているだけではないか」
という疑いが立つ。これは AI読の結論そのものを壊しうる。

## 決定

**作らない。** ただし「面倒だから」ではない。**作る前に、使えるかを測った。**

    Google カスタム検索（結果をJSで描く）  20
    送り先が `#` のみ（JSでしか動かない）    3
    区の外の検索サービスに投げる             1
    区自身のURLで叩ける検索                  0   ← 24自治体すべて

**ブラウザを持たないAIから使える検索窓は、1区も無い。**
実装しても0区でしか動かないので、作る価値が無い。

## この記録の使い道

「サイト内検索を使えば読める」という反論に、**数字で答えられる**ようにした。
判定には入れない（点数には無関係）。根拠（form の抜粋）を区ごとに残してあるので、
人が見て検算できる。

ここが変われば結論も変わる。**区が `?q=` で叩ける検索を1つ用意すれば、
AI読は検索窓を使う実装をする。** そのときは条件に記録して測り直す。
