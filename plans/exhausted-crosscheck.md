# 計画: 「書いていない」を別系統のモデルで突き合わせる

**問い**: 虱潰しで `stopped=exhausted`（読み切った上で書いていない）とした79件は、
Claude 以外に読ませても「書いていない」のままか。

**完了条件**: 79件それぞれを「覆らない／食い違い（人の確認待ち）」に分けた結果が
`analysis/out/crosscheck-exhausted.json` にあり、結論が `plans/decisions/` にある。

## 手順（結果を見る前に固定する）

1. 対象: 79件が読んだ 235判定（ページ×項目）と、陽性対照の「見つけた」16件
2. Codex に、**Claude と同じプロンプト・同じ本文**を渡す。根拠は同じ `check_one` で機械検査する。
   `found=true` かつ根拠が検査を通ったものだけを「見つけた」と数える
3. 陽性対照で 16件中 12件未満しか見つけられないなら、Codex の「無い」は当てにしない
4. Codex が見つけた判定は、Claude（claude-sonnet-5）に同条件でもう1回聞き、次に分ける
   - Claude も今度は見つけた: 1回ごとのぶれ
   - Claude はまた見つけない: 系統の食い違い
5. 食い違いの根拠を人が読み、どちらが正しいかを決める

## 言えること・言えないこと

- 言える: この79件・この2モデルで、覆る候補が何件あったか
- 言えない: Claude が同系統に甘いことの証明。自分の答えを採点する実験ではなく、同じページを別々に読ませた比較である
- Codex の見つけすぎもあり得るので、人が読むまで「Claude の誤り」とは書かない
- Codex は1回だけなので、Codex 自身のぶれは測らない

## 触らないもの

公開データ（`web/data/`）と `analysis/out/sweep_*.json`。直すかどうかは結果を見て別の Issue で決める。
