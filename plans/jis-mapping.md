# AI読の指摘を、JIS X 8341-3 の達成基準に対応づける

Status: 設計（実装は未着手）
関連: Issue #148 / [`plans/read-through.md`](read-through.md) / [`plans/never-looked.md`](never-looked.md)

---

## なぜ要るか

**「AIに読めません」では職員は動けない。** どこを直せばいいのか、直す義務があるのか、
社内で誰に相談すればいいのかが分からない。

一方で自治体には**すでに基準がある**:

- [総務省「みんなの公共サイト運用ガイドライン（2024年版）」](https://www.soumu.go.jp/main_content/000945249.pdf)
  が **適合レベルAA** への準拠を求めている
- 基準は [JIS X 8341-3:2016](https://www.nict.go.jp/info-barrierfree/jis/gaiyou.html)（レベルA 25項目 + AA 13項目）
- 総務省が[無償の評価ツール `miChecker`](https://www.soumu.go.jp/main_sosiki/joho_tsusin/b_free/webaccessibility.html) を配っている
- **2026年8月24日、改正検討会の第1回が開かれた。** WCAG 2.2 準拠へ改正予定で、
  AAの達成基準が**約1.4倍**に増える見込み

**評価軸を自分で発明する必要はなかった。** 国の標準があり、試験方法も定義され、
準拠義務があり、いま改正が動いている。

## 何が言えるようになるか

| いまの言い方 | 対応づけた後 |
|---|---|
| 「AIに読めません」 | 「**達成基準 1.1.1（非テキストコンテンツ・レベルA）に該当します**」 |
| 「手数料が見つかりません」 | （対応づかない。**これはJISの範囲外**） |

**大事なのは、対応づく指摘と対応づかない指摘を分けること。** 全部をJISに寄せない。

## 実測から対応づけられるもの

### ① 画像PDF → **1.1.1 非テキストコンテンツ（レベルA）**

中野区 `ininjyou.pdf` は本文のテキストを持たない。読み取り器でも取れず、
**スクリーンリーダーでも読めない。** これは JIS のレベルA（最低限）に当たる。

実測: 転入届の添付10本中 **1本**（`analysis/out/non-html_tennyu.json`）。

### ② 表の見出しと値の対応が潰れる → **1.3.1 情報及び関係性（レベルA）**

`crawler/htmlutil.py` の表読みを入れた理由がこれ。本文として読むと
どの見出しの列の値かが失われる。**スクリーンリーダーも同じ問題に当たる。**

実測: 表の中にしかない項目があるのは4セル・6項目
（`plans/reader-tools.md` / `analysis/check_tables.py`）。

### ③ リンク題から行き先が分からない → **2.4.4 文脈におけるリンクの目的（レベルA）**

探索台帳の `never_shown` / `shown_not_chosen` の一部はこれ。
「こちら」「詳しくは」だけのリンクは、AIも人も行き先を判断できない。

**実測はこれから**（台帳のリンク題を分類すれば数えられる）。

### ④ 見出しが内容を表さない → **2.4.6 見出し及びラベル（レベルAA）**

「くらし・手続き」の下に転入届が埋もれる構造。
**実測はこれから。**

## 対応づかないもの（JISの範囲外）

**ここを曖昧にしない。** JISに寄せられない指摘こそ、AI読が固有に言えることである。

| AI読の指摘 | なぜJISに対応づかないか |
|---|---|
| **手数料が書かれていない**（22区） | 書いていないことは達成基準の違反ではない。**内容の問題であって形式の問題ではない** |
| 必要書類がリンク先にしか無い | 1階層先にあることは違反ではない |
| 情報が古い（パスポート手数料） | JISは鮮度を扱わない |
| AIが「無料」と推測で答える | サイト側の問題ですらない |

**この4つが、AI読が国の標準では拾えないものを拾っている証拠になる。**
JIS対応づけの価値は「重なるところ」ではなく、**重ならないところが見えること**にある。

## 段

| # | やること | 受け入れ条件 |
|---|---|---|
| ① | **対応表を持つ**（指摘 → 達成基準・レベル・出典） | 4項目すべてに番号とレベルが付き、**対応づかないものは「範囲外」と明記される** |
| ② | ③④を実測する（リンク題・見出し） | 転入届24区で件数が出る |
| ③ | 公開データに出す | 職員が「これはJISのA、これは範囲外」と読める |

**①が先。** 数える前に、何をJISに寄せて何を寄せないかを決める。

## やらないこと

- **JIS の適合試験をしない。** AI読は適合証明の道具ではない。
  試験は `miChecker` と正式な試験方法がある。**そちらの代わりをしない**
- **「JIS準拠」と名乗らない。** 対応づけているだけ
- **全部をJISに寄せない。** 寄らないものが本体

## 改正への構え

改正は2026年度末の見込み。**いま対応表を持っておけば、改正時に差分だけ足せる。**
持っていないと、改正のたびに全部やり直しになる。
