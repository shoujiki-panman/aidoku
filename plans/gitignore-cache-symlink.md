# crawler/cache のシンボリックリンクを無視する（#194）

## 何が起きているか

作業コピーによっては `crawler/cache` が実体ディレクトリではなく、別の作業コピーへの
**絶対パスのシンボリックリンク**になっている（生HTMLキャッシュを1か所で共有するため）。

`.gitignore` の `crawler/cache/` は末尾スラッシュ付きなので **ディレクトリにしか一致しない**。
シンボリックリンクはディレクトリではないので無視されず、`git status` に `?? crawler/cache` と出る。

このまま `git add -A` すると、マシン固有の絶対パスを持つリンクがコミットに入る。
他の環境ではリンク先が存在せず壊れる。

## 直し方

`.gitignore` を `crawler/cache/` → `crawler/cache` にする。
末尾スラッシュを外すと、実体ディレクトリ・シンボリックリンク・ファイルのいずれでも一致する。

リンク自体は手元の都合なので **追跡しない**。無視するだけで、リンクは消さない。

## 完了条件

`git check-ignore -v crawler/cache` が一致を返し、`git status` に `crawler/cache` が出ない。
実体ディレクトリの作業コピーでも従来どおり無視され続ける。
